# ピコの電線ラン

でんきの子ピコが、電線の町から地下ケーブル道を抜けて発電所をめざす横スクロールアクションです。全3ステージ。

**遊ぶ:** https://asanote.github.io/pico-densen-run/

## 操作

| 操作 | キーボード | タッチ | コントローラー |
| --- | --- | --- | --- |
| 移動 | ← → / A D | 左右ボタン | スティック・十字キー |
| ジャンプ（長押しで高く） | Z / Space / ↑ | A | Xbox: A / Switch: A・B |
| ダッシュ・放電（ギガ） | X / Shift | B | Xbox: X・B / Switch: X・Y |
| 一時停止 | P / Esc | 画面タップで再開 | メニューボタン / + − |

## 進化

- **ピコ**: 1回当たるとミス
- **メガ**: 電池で進化。レンガを壊せる
- **ギガ**: 雷コアで進化。B で放電

## ボス

各ステージの最後にボスの部屋があります。部屋に入ると左右の壁が閉じ、ボスを倒すとゴールポールが現れます。

| ステージ | ボス | とくちょう |
| --- | --- | --- |
| 1-1 電線の町 | ガイシガメ | 碍子を背負ったカメ。丸まって1回ころがる |
| 1-2 地下ケーブル道 | ドリルマジロ | ジャンプで飛びかかり、丸まって壁で1回はね返る |
| 1-3 発電所の空 | ダイナモ大王 | ジャンプで飛びかかり、丸まって壁で2回はね返る。いちばん速い |

- ボスは歩く → 丸まる → ころがる → 目を回す、をくり返します。ころがってきたらジャンプでかわします。
- 目を回しているあいだに頭を踏むとダメージ。3回踏めば勝ちです。
- ギガの放電でも少しずつ削れます（12発で倒せます）。
- 1回踏まれるたびにボスは怒って少し速くなります。
